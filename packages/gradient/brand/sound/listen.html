Spectrum, six ways

Every version keeps Spectrum's idea: three notes at the mark's strengths, held while the tone opens from blue to orange, then closes back and settles on a low B, home. They differ in voice, tune and pace. Pick one, and the long intro and the product sounds are built from it.

    Every file is synthesised from code in the gradient repo (packages/gradient/brand/sound/render.py), so we own every note. Levelled to −16 LUFS with true peak under −1 dBTP. Each band is a note: height is pitch, shade is strength, length is how long it holds.

Three directions for the Shades sound

Each logo is three notes at the mark's three strengths: full, three-quarter, half. They share that idea and differ in tune and voice. Pick one, and the long intro and the product sounds are built from it.

    Every file is synthesised from code in the gradient repo (packages/gradient/brand/sound/render.py), so we own every note. Levelled to −16 LUFS with true peak under −1 dBTP. The bars show each note: height is pitch, shade is strength, position is time.

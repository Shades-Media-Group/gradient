# Getting help

- **How do I…?** Start with the [docs](docs/README.md) and the [website](https://gradient.shades.md), then ask in [Discussions](https://github.com/Shades-Media-Group/gradient/discussions).
- **Something is missing:** open a [request](https://github.com/Shades-Media-Group/gradient/issues/new?template=request.yml) for a token, component, icon or rule.
- **Something is broken:** open a [bug report](https://github.com/Shades-Media-Group/gradient/issues/new?template=bug.yml).
- **A security issue:** follow [SECURITY.md](SECURITY.md).
- **Using the Shades brand:** read [TRADEMARKS.md](TRADEMARKS.md), or email support@shades.md.

Gradient is maintained by [Shades Media Group](https://shades.md).
